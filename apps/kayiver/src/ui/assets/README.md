# Bundled device artwork

`alpine-blue.png` is an original AI-generated wallpaper, created with the
built-in image generation tool for this Kayiver design. It contains no actual
user desktop data and is bundled for offline rendering.

Prompt: "Create a cinematic, exceptionally detailed alpine lake landscape at
blue hour, clean mountain silhouettes with snow peaks, subtle still-water
reflections, deep ink blue and steel-blue palette, a tiny restrained warm
horizon glow, rich photographic texture. Wide panoramic landscape. No people,
buildings, text, logos, borders, interface, stars or fantasy objects. Mountain
range across the middle and dark blue foreground lake."

Device bezels, laptop bases and stands are generated by CSS in the editor.
They are generic representations, not licensed manufacturer photographs.
The screen rectangle alone remains the geometry/hit-test reference.
